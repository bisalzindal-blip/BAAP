# BAAP — How to Run

## Bacterial Annotation & Analysis of Proteases

BAAP (Bacterial Annotation & Analysis of Proteases) is a computational
pipeline for identifying and characterizing protease candidates from
bacterial genome sequences.

The pipeline performs automated protease annotation and analysis using
MEROPS, DIAMOND, InterProScan/domain evidence, and downstream
classification steps.


# Google Colab

This is the **recommended method for most users**.

No local Python installation is required.

Google Colab provides the computational environment required to run BAAP.
